# 🍽️ Sabor & Click

> **Uma solução digital rápida e prática para aproximar utilizadores da gastronomia através de menus e pedidos num clique.**

---

## 📌 Sobre o Projeto

O **Sabor & Click** é uma aplicação web desenvolvida com o objetivo de simplificar o acesso a opções gastronómicas, permitindo que os utilizadores explorem pratos, consultem detalhes de cardápios e façam pedidos de forma intuitiva.

### 🚀 Funcionalidades
- 🍕 **Catálogo de Pratos/Cardápio:** Visualização intuitiva de refeições, categorias e preços.
- 🔍 **Busca e Filtros:** Pesquisa rápida por alimentos, ingredientes ou categorias.
- 🛒 **Carrinho / Pedido:** Adição simples de itens para conclusão de pedidos num clique.
- 📱 **Design Responsivo:** Interface adaptada para navegação em telemóveis e computadores.
